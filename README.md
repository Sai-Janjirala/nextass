# Cineverse

An independent film and television journal and streaming web application. Curated reviews, honest rankings, watchlist management, and detailed information on movies and series.

## Features

- **Movies & Series Catalog**: Browse curated movies and series with detailed metadata, trailers, and cast information.
- **Top Rated Rankings**: Filter and explore top-rated films and television series.
- **Reviews & Ratings**: Read community reviews and submit your own ratings and critiques.
- **Personal Watchlist**: Save and manage movies and series you want to watch.
- **Responsive Modern UI**: Built with Next.js App Router, Tailwind CSS, and Lucide icons.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

To create an optimized production build:

```bash
npm run build
npm run start
```
